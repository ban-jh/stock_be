# Stock Backend 문서

이 디렉터리는 개인용 AI 투자 관리 시스템(AIM) 백엔드의 개발 절차와 설계를 기록합니다.

## 문서 목록
- 00-development-workflow.md: 로컬 설정, 구현 순서, 변경·검토 절차
- 01-architecture.md: 현재 구조, 모듈 책임, 실행 흐름, 데이터 및 보안 설계
- 02-change-log.md: 설계·구현 변경 이력

## 문서 갱신 규칙
백엔드 코드나 설정을 변경할 때 관련 설계 문서와 변경 이력을 같은 작업에서 갱신합니다. API·DB·실행 정책 변경은 설계 문서에, 구현 순서나 환경 변경은 개발 절차서에 반영합니다. 문서와 구현이 달라지면 구현 기준으로 문서를 바로잡고 차이를 이력에 남깁니다.
## 설계 산출물
- 설계/01-database-schema.md: MariaDB 테이블 명세, Mermaid ERD, 관계·제약·인덱스 및 적용 절차
- 설계/02-domain-api.md: 2단계 API 계약, 계층 책임, 입력/오류 정책과 미구현 경계
- 설계/03-toss-api-prerequisites.md: 3단계 토스증권 API 연결 전 사용자 준비 항목과 접을 수 있는 상세 절차
- 설계/03-toss-api.md: 토스 OAuth, 시세/계좌 어댑터, 오류 처리 및 보안 경계
